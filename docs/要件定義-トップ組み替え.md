# 要件定義: Aiplun Studio 公式サイト(aiplun-studio.jp)— トップページの組み替え
状態: 確定(2026-11-17) / 作成: Claude Code

## 目的
トップページを短くし、訪問者が「自分の困っている業務」から迷わず相談に進めるようにする。
2026-11-17 に関西の同業10社(AI 導入・システム開発・Web 制作を中小企業向けに行う会社)のトップページを比べた結果、自社のトップは欄が17個・PC 約14,400px と最も長かった。他社でよく使われていた型(業務の名前から選ぶ入口、「まず試す / 仕組みから変える」の2段階の入口、事例を変化で見せる、問い合わせ直前のよくある質問)を、自社の今のデザインと文言で取り入れる。
分析の記録: Vault `プロジェクト/AIPLUN事業.md` の 2026-11-17「同業他社のトップページ分析」。

## 利用者
- サイトの訪問者: 中小企業・個人事業の経営者、事務・現場の責任者、新規事業の担当者(スマホでの閲覧も多い)
- 運営者: 代表の尾島 蓮瑛(一人で運営)

## 組み替え後のトップの並び
1. ファーストビュー(今のまま)
2. 業務の名前から選ぶ入口(R13。今の「こんな困りごと」の欄を置き換える)
3. できること(今の4つの支援)+ 2段階の入口(R14)
4. 実績・制作例(変化を一行で添える — R15)
5. 3つの柱 + 進め方(R16。今の「成果までの流れ」を統合)
6. 費用の目安(今のまま)
7. 代表について(今のまま)
8. よくある質問 3つ(R17)
9. 問い合わせ(今のまま。入口3つ・フォーム)

トップから外すもの: AI の業種別の例と削減額の試算(R18 でサービスページへ移す)、無料相談の説明の欄(R17 で問い合わせ欄と重なるため外す)、ブログの欄(R19 でリンク1つにする)。
