# 要件定義: Aiplun Studio 公式サイト(aiplun-studio.jp)の修正 — レビュー項目2〜11
状態: 確定(2026-11-17) / 作成: Claude Code

## 目的
中小企業・個人事業の経営者や業務担当者が、トップページを見て「何をしてくれる会社か・信頼できるか・費用感と進め方」をすぐに理解し、無料相談に進めるようにする。
2026-11-17 のサイトレビュー(案件ノート `プロジェクト/AIPLUN事業.md`)で挙げた修正点のうち、項目2〜11を直す。項目1(連絡先を独自ドメインのメールにする)は今回やらない。

## 利用者
- サイトの訪問者: 中小企業・個人事業の経営者、事務・現場の責任者、新規事業の担当者(専門知識なし、スマホでの閲覧も多い)
- 運営者: 代表の尾島 蓮瑛(一人で運営)

## 参考にしたプロのデザインの原則(調査結果)
NotebookLM で次の情報源を調べた結果。各要件はこれに沿う。
- セクションは訪問者の疑問の順に並べる: 何をするか → 誰向けか → なぜ信頼できるか → サービス → 次に何をすればよいか。トップは全部を説明するページではなく、各サービスページへの「案内役」にする。
- 主張のすぐ近くに証拠を置く。証拠は1か所にまとめず、関係する主張の近くに分けて置く。「多くの企業に信頼」のような曖昧な表現より、具体的で確かめられる事実を置く。
- ストック写真ではなく実在の人物の写真を使う。成果が出るまでの進め方を見せる。
- 主ボタン(無料相談)の横に、副ボタン(費用を見る・実績を見る)を置く。
- 見出しは短く、一定のデザインでそろえる。スマホで縦に間延びしたレイアウトにしない。表示速度とレイアウトの安定性を優先する。
- 出典: [NN/g Homepages](https://www.nngroup.com/topic/homepages/) / [Blend: The 10 best B2B homepage examples](https://www.blendb2b.com/blog/the-10-best-b2b-homepage-examples) / [Directive: 15 B2B website best practices](https://directiveconsulting.com/ca/blog/15-b2b-website-best-practices-for-2026-built-for-buyers-not-just-browsers/) / [Service business homepage best practices](https://selfimprovingwebsites.pages.dev/blog/service-business-homepage-design-best-practices-for-lead-generation/)
