# 要件定義: Aiplun Studio 公式サイト(aiplun-studio.jp)— 他社サイトのレイアウトを参考にした改善
状態: 確定(2026-11-17) / 作成: Claude Code

## 目的
トップページを訪れた人が、自分の段階(まず相談したい/見積もりがほしい/費用だけ知りたい)に合った入口をすぐに選べるようにする。あわせて、Aiplun Studio の強みを短い3つの柱で一目で分かるようにする。
株式会社ヤプリのトップページ(https://yapp.li/)の**並べ方の考え方**を参考にする(2026-11-17 ユーザー指示「レイアウトを参考にしてほしい」)。

## 利用者
- サイトの訪問者: 中小企業・個人事業の経営者、事務・現場の責任者、新規事業の担当者(スマホでの閲覧も多い)
- 運営者: 代表の尾島 蓮瑛(一人で運営)

## 参考にする考え方(ヤプリのトップページから)
- 強みを3つの柱にし、英単語のラベルと番号(01〜03)、短い見出しで並べる。
- ページ末尾の問い合わせ欄で、目的の違う入口(相談・見積もり・資料)を横に3つ並べ、それぞれに一行の説明を付ける。
- ヤプリのデザイン(色・形・イラスト・写真)、文章、画像、コードは使わない。Aiplun Studio の今のデザインの部品と文言で作る。

## やること(最初の版)
- [x] R11: 問い合わせ欄(`#contact`)の先頭に、相談の入口を3つ並べる。
  - 「無料で相談する」: 何を導入するか決まっていない段階からの相談。押すとフォームへ移動する。
  - 「見積もりを依頼する」: 作りたいもの・直したいことが決まっている人向け。押すとフォームへ移動し、「ご相談の種類」が新しい選択肢「見積もり依頼」になる。送信される本文の先頭に【見積もり依頼】が付く(今の仕組みと同じ)。
  - 「費用の目安を見る」: まず費用感を知りたい人向け。`/plans` へ移動する。
  - PC は横に3つ、スマホは縦に3つ(1つあたり短く)並べる。
- [x] R12: 「04 — SUPPORT & RESULTS」の欄を、3つの柱に組み直す。今の内容(サポートの説明と 01〜04 の4項目)を、意味を変えずに3つにまとめる。
  - 01 ADVISE「必要かどうかから、一緒に考える。」— 今の 01 の内容。
  - 02 MEASURE「作った機能ではなく、変わった仕事で確かめる。」— 今の 02・03・04 の内容(目標と測定方法を事前に決める/業務に合った指標/試算と実際の結果を分けて伝える)。
  - 03 SUPPORT「導入後も、相談できる。」— 今のサポートの説明(相談対応・利用状況の確認・改善提案、条件は契約前に確認)。
  - 各柱は 番号・英単語のラベル・見出し・2文程度の説明。指標の例や試算の注意などの細かい文は、スマホでは「続きを読む」の中に入れる(今と同じ仕組み)。
  - PC は横に3列、スマホは縦に並べる。

## やらないこと
- ダウンロード資料(PDF)の作成と配布の入口
- 事例に成果の数字を載せること(載せられる数字がない — 2026-11-17 ユーザー回答)
- 業種名が横に流れる帯、セミナー・ニュースの欄
- 見積もり専用の新しいフォームや画面
- ヤプリのデザイン・文章・画像・コードの流用

## 完成の条件(受け入れ条件)
- R11: トップの問い合わせ欄に入口が3つ表示される。「無料で相談する」を押すとフォームへ移動する。「見積もりを依頼する」を押すとフォームへ移動し、「ご相談の種類」が「見積もり依頼」になっている。「費用の目安を見る」を押すと `/plans` が開く。PC(1440px)で横に3つ、スマホ(375px)で縦に3つ並び、横にはみ出さない。
- R12: 「04 — SUPPORT & RESULTS」に柱が3つ(01 ADVISE・02 MEASURE・03 SUPPORT)表示される。今の4項目とサポートの説明にあった事実(導入しない選択も含める/目標と測定方法を事前に決める/指標の例/削減額は試算で導入成果ではない/条件は契約前に確認)がすべて残っている。PC で横に3列、スマホで縦に並ぶ。
- 共通: スマホ(375px)でトップ全体の高さが 12,000px 以下(今は約11,880px)。lint・テスト・本番ビルドが通る。コンソールエラーがない。「サイトの動きを止める」で動きが止まる。
